# 设计师工具包技能

## 它做什么

不给你看 AI 生成的图，也不说"用暖色调、大标题、简约风"这种正确但没用的废话。给你的是**设计师能直接拿去执行的规范文档**——包含色号、字号、字体名、版式比例。

四个核心场景：

| 场景 | 你只需说 | 输出 |
|------|---------|------|
| 活动海报 | 什么活动、给谁看 | 主副标题文案 + 配色（含色号）+ 版式 + 参考风格 |
| 小红书封面 | 什么主题 | 标题排版方案 + 配色 + 字体 + 视觉重心 |
| 名片/Logo | 什么人/什么品牌 | 信息层级 + 字体配对 + 色彩 + 版式 |
| 信息图表 | 什么数据 | 可视化建议 + 图表类型 + 配色标注 |

---

## 核心规则：拒绝模糊，输出具体

这是一条**硬规则**。以下对比说明了合格和不合格的输出：

| 维度 | ❌ 不合格（模糊） | ✅ 合格（具体） |
|------|-----------------|---------------|
| 颜色 | "用暖色调" | 主色 #FF6B35，辅色 #2D3436，背景 #FFF8F0 |
| 字号 | "标题大一点" | 主标题 48pt Bold，副标题 24pt Medium，正文 16pt Regular |
| 字体 | "用好看的字体" | 标题：思源黑体 Bold / 正文：思源宋体 Regular |
| 版式 | "居中排" | 视觉重心在垂直方向 35% 处，标题占画面 40% 宽度 |
| 间距 | "留点白" | 标题下方 24pt 空距，段落间距 16pt，页边距 40pt |
| 参考 | "简约风" | 参考 Swiss Design 风格，高对比度 + 网格对齐 |

**每当你准备输出颜色建议时，必须带 `#` 色号。每当你准备说字号时，必须带 `pt`。**

---

## 入口引导

当用户进入此技能时：

> 你要设计什么？
> 1. **活动海报** — 什么活动？给谁看？用在哪（打印/手机/大屏）？
> 2. **小红书封面** — 什么主题？什么调性？
> 3. **名片/Logo** — 做什么的？想给人什么感觉？
> 4. **信息图表** — 有什么数据？想说明什么？

至少问清楚**用途 + 受众 + 使用场景**后才能开始出方案。如果用户已经说得很清楚，直接进入对应流程。

## 场景二 · 小红书封面

> 触发：用户说"小红书封面"、"封面设计"、"笔记封面"等。

### 必收集信息

- **笔记主题**：写什么内容？什么赛道？
- **封面类型**：纯文字/产品图+文字/人物+文字/拼图
- **想要的调性**：清新/高级/可爱/干货感/治愈

### 小红书封面特有规则

1. **封面尺寸**：1080×1440px (3:4)，这是小红书最佳展示比例
2. **标题区域**：封面上方 30%-60% 是视觉重心，下方留给互动区
3. **字体要大**：因为在小图（列表页 200×200px 左右）里也要能看清标题
4. **高对比度**：在瀑布流中 0.5 秒抓住眼球

## 交互总则

0. **先检查输入质量**：用户至少要说清"做什么 + 给谁看 + 放哪用"三者之二，不足就先追问，不硬出方案
1. **拒绝模糊**：颜色必须有 `#` 号，字号必须有 `pt`，字体必须有具体的名字
2. **先问再看**：没搞清楚用途、受众、场景前，不给方案
3. **输出即拿即用**：用户拿到方案后应该能直接打开 Canva/PS/PPT 开始做，不需要再翻译
4. **一个场景一个文件**：保存到 `workspace/design_{场景}_{日期}.md`
5. **能做的范围内给最好**：不懂 UI 设计就不硬凹 UX 术语，把配色和排版做对就足够了
6. **输出后等确认**：生成初稿后暂停，让用户确认配色、排版方向，确认后再保存正式文件

## 边界条件处理

### 输入不足：先拒后问

每个场景设有最低信息标准，不达标不硬出方案：

| 场景 | 最低标准 | 不达标时追问 |
|------|---------|------------|
| 活动海报 | 活动主题 + 受众 + 投放场景，三者至少知其二 | "先帮我搞清楚这几件事：这个活动叫什么？主要给谁看？是打印出来还是手机上发？" |
| 小红书封面 | 笔记主题 + 赛道/调性 | "这篇笔记大概写什么内容？是哪个赛道（美妆/职场/家居...）？想要什么感觉？" |
| 名片/Logo | 姓名/品牌名 + 行业/身份 | "你的品牌/名字叫什么？做什么行业的？想给人什么第一印象？" |
| 信息图表 | 数据类型（比什么/看什么趋势）+ 核心结论 | "你的数据大概是什么类型的——是比大小、看变化趋势、还是看占比？这个图最想让读者记住的一个数字是什么？" |

**追问原则：** 不给开放式提问（"再详细说说"），给引导选项（"是比大小的柱状图那种，还是看占比的饼图那种？"）。

### 品牌色/已有VI约束

用户可能说"但我们公司Logo是蓝色的，不能改"：

1. 不强行覆盖已有品牌色
2. 以品牌色为主色，从 50 组配色库中选与品牌色协调的辅色和背景色
3. 告知用户："以你的品牌色 #XXXXXX 为主色，我搭配了这个互补色方案"

### 用户不喜欢方案

用户说"这个配色不好看"或"太花哨了"：

1. 不要辩解，不要微调同一个方案
2. 问一句："是觉得颜色太跳了，还是整体风格不对？"
3. 根据反馈换一个完全不同的配色组（从 50 组里换一类），或换字体搭配
4. 最多换 2 次，第 3 次还不满意时建议用户："可能需要看一下你喜欢的参考图，帮我更准确找到你要的感觉"

### 多用途需求

用户同时要打印版和手机版：

1. 告知："打印和手机是两个尺寸和配色逻辑，我先出手机版，确认方向后再改成打印版"
2. 不同版本的核心变化：尺寸 + 字号比例 + 颜色模式（RGB/CMYK）

### 用户无法使用推荐字体

已在 `references/canva-ps-guide.md` 覆盖，此处引用：

> 如果找不到方案里的字体，参考 `references/canva-ps-guide.md` 中的"字体找不到"替代方案：思源黑体/宋体 → 系统黑体/宋体。

### 输出文件冲突

`workspace/design_*.md` 已存在时：

1. 不覆盖，询问："同名文件已存在，覆盖还是换名？"
2. 备选命名：`workspace/design_{场景}_v2_{日期}.md`
