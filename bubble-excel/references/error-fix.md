# Excel 常见报错修复方法

每种报错的含义、最常见原因、一步一步怎么修。

---

## #N/A — 找不到值

### 含义
公式在查找范围内没找到匹配的值。最常见于 VLOOKUP/XLOOKUP/MATCH。

### 常见原因（按概率排序）

1. **两边数据不一致（80% 的情况）**
   - 有空格："张三" vs "张 三"
   - 有不可见字符：从网页/系统导出的数据常有
   - 全角半角："ＡＢＣ" vs "ABC"
   - 数字存成了文本格式

2. **查找区域没有包含目标值**：比如要查"张三丰"但表里只有"张三"
3. **VLOOKUP 的最后一个参数写成了 TRUE**：近似匹配可能返回意想不到的行

### 修复步骤

**Step 1：检查数据一致性**
```excel
=A2=B2
```
如果返回 FALSE，说明两个格的值不一样，即使看上去一样。逐个排查空格和不可见字符。

**Step 2：清洗数据**

去除首尾空格：
```excel
=TRIM(A2)
```

去除所有空格和不可见字符：
```excel
=CLEAN(TRIM(A2))
```

**Step 3：用 IFERROR 兜底**
```excel
=IFERROR(VLOOKUP(A2, B:C, 2, FALSE), "未找到")
```

## #REF! — 引用失效

### 含义
公式引用了一个不存在的单元格。最常见于删除行列后、复制粘贴公式后。

### 常见原因

1. **引用的列/行/工作表被删掉了**
2. **复制公式时引用范围跑偏**
3. **INDIRECT 函数引用的工作表名变了**

### 修复步骤

**Step 1：点击报错单元格，查看公式栏**

被删除的区域会显示 `#REF!`，比如：
```
=VLOOKUP(A2, #REF!, 2, FALSE)
```

**Step 2：重新选择正确的区域**

选中公式中的 `#REF!` 部分，用鼠标重新框选正确的区域即可。

**Step 3：使用表格（Ctrl+T）避免未来再出现**

把数据区域转为"表格"后，引用会自动跟着数据扩展，不再出现 #REF!。

## #VALUE! — 数据类型不对

### 含义
公式遇到了不该出现的类型，比如把"hello"当数字来算。

### 常见原因

1. **数字被存成了文本**：单元格左上角有绿色三角标记
2. **公式里混入了文本**：`=A2+B2` 但 A2 是"无"
3. **日期被当成文本处理**
4. **SUM/AVERAGE 范围内包含了文本格**

### 修复步骤

**Step 1：定位文本型数字**

选中列 → 数据 → 分列 → 直接点完成（不选任何分隔符）。这会把文本型数字强制转成数字。

**Step 2：用 VALUE 函数转换**
```excel
=VALUE(A2)
```

**Step 3：用 IFERROR 跳过文本格**
```excel
=IFERROR(A2+B2, 0)
```

## #DIV/0! — 除以零

### 含义
除以了 0 或空单元格。

### 常见原因

1. **分母单元格为 0**
2. **分母单元格为空**：Excel 把空格当 0 处理
3. **AVERAGE 范围内的数据全是空的或文本**

### 修复步骤

**Step 1：加 IF 判断**
```excel
=IF(B2=0, "无数据", A2/B2)
```

或更完善：
```excel
=IF(OR(B2=0, B2=""), "", A2/B2)
```

**Step 2：整体兜底**
```excel
=IFERROR(A2/B2, "")
```

## #NAME? — 函数名或名称错误

### 含义
Excel 不认公式里的某个名字。最常见于函数名拼写错误。

### 常见原因

1. **函数名拼写错误**：`VLOKUP`（少了个 O）→ `VLOOKUP`
2. **中文版 Excel 用了英文函数名**或反过来
3. **引号没配对**：`=IF(A2="是", "通过")` 少了一个引号
4. **区域名称不存在**：引用了没定义过的"命名区域"

### 修复步骤

**Step 1：检查拼写**

对照 `references/common-functions.md` 确认函数名。

**Step 2：检查引号**

公式中成对的引号必须数量相等。

**Step 3：中英文兼容**

用英文函数名 + 英文逗号最保险：
```excel
=VLOOKUP(A2, B:C, 2, FALSE)       ← 任何版本都能用
```

## #NUM! — 数字不合法

### 含义
计算结果超出了 Excel 能处理的范围。

### 常见原因

1. **数字太大**：超过 9.9E+307
2. **数字太小**：小于 -9.9E+307
3. **给负数开了平方根**：`=SQRT(-1)`
4. **IRR/RATE 等财务函数的迭代不收敛**

### 修复步骤

**Step 1：检查输入数据**

有没有明显不合理的数字？

**Step 2：给负数取绝对值再算**
```excel
=SQRT(ABS(A2))
```

## ##### — 列宽不够

### 含义
单元格太窄，内容显示不全。不是公式错误，只是显示问题。

### 修复

双击列标右边框，自动调整列宽。或手动拉宽。

**注意：** 如果是日期类型且出现 `#####`，说明日期值是负数（Excel 不认负日期），用 `=ABS(日期)` 检查。

## 快速排查三步法

任何报错都按这个顺序排查：

1. **点开报错格，看公式栏** — 是否有 #REF! 说明引用丢失
2. **按 F9 逐段计算** — 在公式栏选中一段 → 按 F9 看中间结果 → Ctrl+Z 撤销
3. **用 IFERROR 先兜底** — 公式外包 IFERROR，定位是哪个格出的错
