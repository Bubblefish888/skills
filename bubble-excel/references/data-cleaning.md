# 数据清洗三步法

拿到任何一张原始数据表，按这三个步骤走一遍，80% 的问题都能解决。

---

## 第一步：去脏 — 清除格式和垃圾

### 1.1 去除多余空格

列首列尾空格 + 中间多余空格是最常见的数据污染。

```excel
=TRIM(A2)        ← 去除首尾空格 + 中间多余空格
=CLEAN(A2)       ← 去除不可见字符（换行符、制表符等）
=CLEAN(TRIM(A2)) ← 两者一起用
```

### 1.2 统一字母格式

```excel
=UPPER(A2)  ← 全部大写
=LOWER(A2)  ← 全部小写
=PROPER(A2) ← 首字母大写
```

对于全角/半角问题（中文输入法误切），用：
```excel
=ASC(A2)   ← 全角转半角
```

### 1.3 删除重复行

选中全表 → 数据 → 删除重复项 → 选择判断重复的列 → 确定。

如果只用部分列判断重复（比如姓名相同就算重复不管其他列），只勾选那几列。

---

## 第二步：定型 — 统一数据格式

### 2.1 数字格式统一

**文本转数字：**
```
选中列 → 数据 → 分列 → 直接点完成
```
或：
```excel
=VALUE(A2)
```

**数字转文本（防止身份证号变成科学计数法）：**
```
选中列 → 右键设置单元格格式 → 文本 → 重新输入
```
或导入时选择列的数据类型为"文本"。

### 2.2 日期格式统一

不同系统导出的日期格式可能完全不同，统一处理：

```excel
=DATEVALUE(A2)                    ← 文本日期转真日期
=TEXT(A2, "yyyy-mm-dd")           ← 日期转统一格式文本
=DATE(YEAR(A2), MONTH(A2), DAY(A2)) ← 分解再重组
```

**注意：** 如果日期是 8 位数字（20240101），用：
```excel
=DATE(LEFT(A2,4), MID(A2,5,2), RIGHT(A2,2))
```

### 2.3 金额单位统一

```excel
=A2*10000   ← 如果有的行是"万元"有的是"元"
=ROUND(A2,2) ← 统一保留两位小数
```

## 第三步：补缺 — 处理空值和异常

### 3.1 定位所有空值

1. 选中区域
2. Ctrl+G → 定位条件 → 空值 → 确定
3. 所有空格同时被选中

### 3.2 填上空值

#### 用上一个格的值填充（如"同上"）：

选中空格后 → 输入 `=上面那个格` → Ctrl+Enter

如：空格在 B3，上面是 B2，输入 `=B2` → Ctrl+Enter。

#### 用固定值填充：

在空格处输入统一值（如"无"、"0"、"未知"）→ Ctrl+Enter。

#### 用 IF 判断自动处理：

```excel
=IF(A2="", "待补充", A2)
```

### 3.3 标记异常值

#### 找离群值：

```excel
=IF(OR(A2<下限, A2>上限), "异常", "正常")
```

#### 条件格式标记：

选中数据列 → 开始 → 条件格式 → 突出显示单元格规则 → 大于/小于。

## 清洗后的验证

每次洗完数据后，用这几个公式快速自检：

| 检查什么 | 公式 | 说明 |
|---------|------|------|
| 还有没有空格 | `=COUNTA(区域)` | 数非空格数，对比预期 |
| 有没有数字型的错误 | `=SUM(区域)` | 如果有 #VALUE!，说明还有文本混入 |
| 有没有重复 | 选中列 → 条件格式 → 重复值 | 一目了然 |
| 日期范围对不对 | `=MIN(日期列)` / `=MAX(日期列)` | 检查最早和最晚日期是否合理 |
| 数值范围对不对 | `=MIN(数值列)` / `=MAX(数值列)` | 有没有离谱的数字 |

---

## 常见数据源清洗要点

| 数据来源 | 典型问题 | 优先处理 |
|---------|---------|---------|
| 系统导出 | 文本型数字、空格、换行符 | 分列转数字 + CLEAN |
| 网页复制 | HTML 标签、全角数字、不可见字符 | CLEAN + ASC |
| 人工录入 | 错别字、大小写不统一、格式不一致 | TRIM + 替换 + 数据验证 |
| 其他系统接口 | 日期格式不对、编码问题、分隔符不同 | DATEVALUE + 分列 |
