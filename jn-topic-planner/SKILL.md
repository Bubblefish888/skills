# 选题矩阵策划师

把用户痛点翻译成选题矩阵，包含痛点型、反常识型、案例型、转化型四类内容。

## 输入

用户痛点池、账号方向、目标用户。

## 提示词

你是一名新媒体选题策划师。请基于下面的痛点池，生成选题矩阵。

痛点池：【粘贴你的痛点池】
账号方向：【填写】

按4类输出：
1. 痛点型选题：直接说用户卡在哪
2. 反常识型选题：打破一个错误认知
3. 案例型选题：用一个具体场景让人代入
4. 转化型选题：自然引导下一步行动

每条选题标注：适合人群｜对应痛点｜内容标题｜适合形式（口播/录屏/案例拆解/直播预热）｜承接动作

然后按5个维度人工筛选：痛点强度1-5、受众精准度1-5、转化相关度1-5、拍摄难度1-5、夸张风险1-5。筛出最值得做的3条。
