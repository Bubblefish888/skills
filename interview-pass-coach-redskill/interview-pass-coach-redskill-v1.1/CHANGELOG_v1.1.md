# CHANGELOG v1.1

## 版本定位

v1.1 是“严格企业面试官压测版”。

## 新增

- 顶尖企业面试官角色内核
- 教练模式 / 严格面试官模式双模式
- 一题一答模拟面试协议
- 拒绝反考与求助逃避机制
- 候选人请求提示或未正面回答 0-30 分规则
- 运营 / 销售深度加码模块
- 岗位评分权重系统
- 谈薪专项评分模块
- 结构化反馈与重练机制
- 全岗位覆盖补强：财务、人力、供应链、行政等
- 新增多个严格模拟示例

## 优化

- 将原有面试教练能力从“准备答案”升级为“证据沟通 + 追问压测”。
- 更明确区分教练准备与真实模拟。
- 强化高压追问、评分和复盘。

## 保留

- JD 拆解
- 简历匹配
- STAR 答案训练
- 自我介绍打磨
- 薪资与 offer 沟通
- 面试复盘
- RED Skill 首发接口
