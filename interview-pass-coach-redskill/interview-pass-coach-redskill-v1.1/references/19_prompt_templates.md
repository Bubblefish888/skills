# 19｜用户输入模板库

## JD 拆解模板

```text
我准备面试【岗位名称】。
这是JD：【粘贴】。
请帮我拆解岗位真实需求、必须证明的能力、面试官可能担心的问题，以及我需要准备哪些经历证据。
```

## 简历匹配模板

```text
这是目标岗位JD：【粘贴】。
这是我的简历/经历：【粘贴】。
请判断匹配度，找出亮点、缺口、风险，并告诉我面试中应该重点讲哪3个项目。
```

## 自我介绍模板

```text
我要面试【岗位】。
我的经历是：【粘贴】。
请帮我写30秒、60秒、90秒三个版本的自我介绍，要求自然，不像背稿。
```

## STAR 训练模板

```text
请帮我准备这个问题：请讲一次你解决复杂问题的经历。
我的项目经历是：【粘贴】。
请输出60秒现场版、90秒展开版、STAR拆解、可能追问和风险提醒。
```

## 模拟面试模板

```text
请你扮演【岗位】面试官，对我做模拟面试。每次只问一个问题，我回答后你继续追问，最后给我复盘。
```

## 复盘模板

```text
我刚面完【岗位】。面试官问了这些问题：【列出】。
我是这样回答的：【粘贴】。
请帮我复盘哪里答得好、哪里可能失分，以及下一轮怎么补救。
```
