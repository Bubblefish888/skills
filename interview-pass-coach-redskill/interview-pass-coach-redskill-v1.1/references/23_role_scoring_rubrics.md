# 23｜岗位评分权重系统

## 运营 / 销售岗位

满分 100 分：

- 专业知识与经验：15
- 数据分析能力：18
- 策略思维：18
- 执行力：15
- 市场敏感度：12
- 沟通表达能力：12
- 抗压能力：7
- 创新思维：3

适用判断：候选人是否真正做过业务、能否用数据和过程证明结果、是否懂用户/客户/市场、能否落地执行。

## 技术岗位

- 专业知识与经验：25
- 数据分析 / 问题定位能力：25
- 技术策略 / 架构思维：10
- 执行落地：10
- 行业技术敏感度：5
- 沟通表达能力：5
- 抗压能力：5
- 创新思维：15

适用判断：技术基本功、项目深度、问题定位、系统思维、工程落地和解释复杂问题的能力。

## 产品岗位

- 专业知识与经验：15
- 数据分析能力：20
- 策略思维：20
- 执行力：15
- 市场敏感度：12
- 沟通表达能力：10
- 抗压能力：5
- 创新思维：3

适用判断：需求判断、优先级、用户洞察、商业理解、跨部门推进。

## 管理岗位

- 专业知识与经验：10
- 数据分析能力：15
- 策略思维：25
- 执行力：20
- 市场敏感度：10
- 沟通表达能力：10
- 抗压能力：7
- 创新思维：3

适用判断：战略判断、资源配置、团队建设、冲突处理和结果负责。

## 其他岗位适配

财务、人力、供应链、行政等岗位不简单套通用模型，应先判断岗位核心任务：

- 财务：准确性、合规意识、预算分析、风险控制、业务支持
- 人力资源：招聘判断、组织理解、沟通协调、制度边界、业务伙伴意识
- 供应链：成本、交期、库存、供应商管理、风险预案
- 行政：服务意识、流程管理、成本控制、突发事件处理、跨部门协调
- 设计：审美判断、业务目标、作品表达、修改协作、交付效率
- 内容：选题、用户情绪、结构表达、数据复盘、平台理解
