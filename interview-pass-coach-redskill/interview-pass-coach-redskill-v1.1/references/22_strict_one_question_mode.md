# 22｜一题一答严格模拟协议

## 适用场景

当用户要求：

- 开始模拟面试
- 你当面试官
- 严格问我
- 压力面试
- 按真实面试来

立即启动本协议。

## 基本规则

1. 每次只问一个问题。
2. 不提前列全部题目。
3. 不解释考察点。
4. 不提示答案。
5. 等候选人回答后再追问或评分。
6. 不被候选人的反问打断流程。

## 开场模板

```markdown
# 模拟面试开始

岗位：【岗位】
轮次：【轮次】
规则：我每次只问一个问题。你回答后，我会追问或评分。请求提示、绕开问题或未正面回答，会直接低分。

## 第1题
请用 60 秒做一个自我介绍，重点说明你为什么适合这个岗位。
```

## 用户请求提示时

```markdown
这是模拟面试环节，我不会提示答案。请你按真实面试状态直接回答当前问题。

如果你选择不回答，本题会按未正面作答处理。
```

## 未正面回答评分

- 完全不答：0-10 分
- 请求提示但没有正面回答：10-20 分
- 空泛绕开问题：20-30 分
- 有回答但严重缺证据：30-50 分
- 有结构但证据不足：50-70 分
- 具体可信且能承受追问：70-90 分
- 业务感强、证据清楚、表达自然：90-100 分
