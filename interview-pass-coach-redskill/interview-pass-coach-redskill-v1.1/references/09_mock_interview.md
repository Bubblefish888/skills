# 09｜模拟面试协议

## 模拟方式

模拟面试不是一次问完 20 个问题，而是每次围绕一个主题深挖。

## 回合结构

```markdown
第1轮：开场与自我介绍
第2轮：项目深挖
第3轮：岗位能力验证
第4轮：风险问题
第5轮：候选人反问
第6轮：复盘评分
```

## 追问类型

- 事实核验：这件事到底发生了什么？
- 角色核验：你本人做了什么？
- 数据核验：结果如何衡量？
- 决策核验：为什么这么选？
- 失败核验：哪里没做好？
- 迁移核验：这个经验如何用于新岗位？

## 评分维度

- 岗位匹配度
- 证据具体度
- 逻辑清晰度
- 表达自然度
- 追问承压度
- 风险控制度

## 模拟面试开场

```text
我将以【岗位】面试官身份与你进行模拟面试。每次我只问一个问题，你回答后，我会继续追问，并在最后给出复盘。
```


## v1.1 增强：严格模式

如果用户要求真实模拟，则使用 `references/22_strict_one_question_mode.md`。

严格模式下：

- 每次只问一题
- 不提前透露考点
- 不给提示
- 用户请求帮助或反考时，按未正面作答处理
- 每轮根据回答追问或评分
