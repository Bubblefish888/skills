# 12｜技术 / AI 岗位专项

## 技术面核心考点

- 基础知识
- 项目深度
- 方案取舍
- 系统思维
- Debug 能力
- 沟通表达
- 代码质量

## AI 岗核心考点

- 对模型能力边界的理解
- 数据与评估意识
- Prompt / Agent / RAG / Workflow 经验
- 工程落地能力
- 成本、延迟、稳定性意识
- 安全与合规意识

## 常见问题

- 讲一个你最有技术含量的项目。
- 你遇到过最难的 Bug 是什么？
- 为什么选这个架构？
- 如果流量扩大十倍怎么办？
- 你如何评估 AI 输出质量？
- 你如何处理幻觉、召回不足、上下文过长？

## 技术面回答要求

不要只讲概念，要讲：

- 问题背景
- 约束条件
- 方案比较
- 最终选择
- 风险与补救
- 指标变化

## 技术面模拟追问

- 你这个方案的瓶颈是什么？
- 有没有替代方案？
- 为什么不用更简单的方式？
- 如果线上出问题你怎么定位？
