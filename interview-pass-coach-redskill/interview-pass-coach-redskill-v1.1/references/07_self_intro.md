# 07｜自我介绍训练

## 自我介绍的目标

不是复述简历，而是让面试官快速形成判断：

- 你是谁
- 你和这个岗位有什么关系
- 你最值得继续追问什么

## 三种版本

### 30 秒版

适合 HR 开场、电话面、快速沟通。

结构：

```text
我是谁 + 最近相关经历 + 与岗位最相关的优势 + 希望重点交流的方向
```

### 60 秒版

适合大多数正式面试开场。

结构：

```text
经历主线 + 2个关键项目 + 与岗位的匹配点 + 结尾落到应聘动机
```

### 90 秒版

适合终面、主管面、跨行业说明。

结构：

```text
职业主线 + 关键能力 + 代表项目 + 结果证据 + 为什么选择这个岗位
```

## 禁止事项

- 不要从出生、学校、兴趣爱好讲起，除非高度相关
- 不要复述简历每一段
- 不要说“我性格开朗、学习能力强”但没有证据
- 不要过度谦虚或过度夸张

## 输出模板

```markdown
## 90秒版

```
