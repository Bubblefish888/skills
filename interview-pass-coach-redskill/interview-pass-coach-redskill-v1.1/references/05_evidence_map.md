# 05｜经历证据地图

## 为什么需要证据地图

面试官不是听故事，而是在找证据。

一个项目至少要拆成：

- 背景
- 目标
- 约束
- 用户/客户/业务问题
- 你的角色
- 你做了什么
- 为什么这样做
- 结果如何
- 失败或不足
- 学到了什么
- 与目标岗位的关系

## 标准证据卡

```markdown
# 项目证据卡

项目名称：
时间：
岗位/角色：
项目目标：
当时难点：
我的具体动作：
关键决策：
协作对象：
结果数据：
失败/不足：
复盘收获：
可证明能力：
适合回答的问题：
```

## 证据等级

### A级证据

有具体场景、具体动作、可量化结果、可追问细节。

### B级证据

有项目和动作，但结果不够清晰。

### C级证据

只有笼统描述，容易被追问击穿。

训练时优先把 B / C 级证据补成 A 级。
