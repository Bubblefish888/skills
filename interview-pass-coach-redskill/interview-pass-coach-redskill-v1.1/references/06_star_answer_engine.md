# 06｜STAR 答案训练引擎

## STAR 不等于流水账

Situation：只讲必要背景。  
Task：说明你要解决什么问题。  
Action：重点讲你的动作和判断。  
Result：讲结果、影响、复盘。

真正的答案重点在 Action 和 Result。

## 60 秒答案结构

```text
一句话背景 + 我面对的任务 + 我做的关键动作1/2/3 + 结果 + 复盘
```

## 90 秒答案结构

```text
背景与目标
关键难点
我的判断
我的动作
结果数据
如果重来我会怎么优化
```

## 输出模板

```markdown
## 问题：请讲一次你解决复杂问题的经历

面试官考点：
- 问题分析能力
- 资源协调能力
- 结果导向

60秒现场版：
……

90秒展开版：
……

STAR拆解：
- S：
- T：
- A：
- R：

可能追问：
1. 你在其中具体负责什么？
2. 数据怎么来的？
3. 最难的一步是什么？

禁止说法：
- “我们做了很多优化。”但不说自己动作。
- “效果很好。”但没有证据。
```

## 自然表达要求

答案不要像作文。可以有口语化连接：

- “这件事当时最难的地方是……”
- “我不是一上来就做方案，而是先……”
- “最后结果有两层，一个是数据上，另一个是流程上……”
