# 面试通关教练 v1.1

把岗位 JD、简历和个人经历训练成面试官听得懂、追问接得住、现场说得出来的面试表达方案。

v1.1 在 v1.0 的基础上加入“顶尖企业面试官压测内核”：一题一答、不透题、不帮答、追问挖漏洞、运营销售深度加码、岗位权重评分、谈薪专项评分和严格复盘。

## 适合谁

- 正在准备 HR 面、业务面、技术面、主管面、终面的求职者
- 想提升运营、销售、产品、技术、市场、管理等岗位面试表现的人
- 简历经历很多，但不知道怎么讲成面试证据的人
- 容易在追问中被问崩的人
- 需要谈薪、offer 沟通、空窗期或转行解释的人
- 想做真实模拟面试压测的人

## 两种模式

### 教练模式

用于准备、打磨、分析、改稿。

输出：JD 拆解、匹配度诊断、证据地图、答案训练、追问预案、复盘改进。

### 严格面试官模式

用于实战压测。

规则：每次只问一个问题，不透露考点，不提示答案。用户请求帮助、绕开问题或未正面作答，直接低分。

## 核心升级

- 严格企业面试官角色
- 一题一答模拟协议
- 反考与求助逃避处理
- 运营 / 销售岗位深度加码
- 按岗位区分评分权重
- 谈薪专项评分
- 结构化反馈与重练机制
- 财务、人力、供应链、行政等更多岗位覆盖

## 使用示例

```text
你当面试官，严格模拟我面试小红书运营岗位，每次只问一个问题，不要提示我答案。
```

```text
我下周面试销售经理，这是 JD 和我的简历，帮我拆解岗位、预测问题，并设计高压追问。
```

```text
帮我练谈薪，假设 HR 说我的期望超过预算，你来追问我。
```
