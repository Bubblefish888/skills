# 口播脚本教练

根据选题生成60-90秒口播脚本，包含开头、中段、后段、结尾完整结构。

## 输入

选题方向、账号风格、目标用户、希望引导的下一步动作。

## 提示词

你是一名新媒体口播脚本教练。请根据以下信息写一条60-90秒的口播脚本。

选题方向：【填写】
账号风格：【填写，如专业温和/犀利直接/轻松幽默】
目标用户：【填写】
希望引导的下一步动作：【填写，如评论扣身份/私信领资料/进群】

脚本结构：
1. 开头戳误区（3秒内抓人）
2. 中段给判断（你的核心观点）
3. 后段给路径（具体怎么做）
4. 结尾引行动（自然引导下一步）

要求：像真人说话，不要书面腔。不要夸张承诺。要有具体场景和判断。
