# 职场动词升级表

将口语化 / 弱动词替换为专业职场动词，让你的文案更有分量。

## 动作类

| 弱动词 | 专业动词 | 使用场景 |
|--------|---------|---------|
| 做了 | 完成 / 主导 / 推动 / 交付 / 落地 | 描述做完了一件事 |
| 参与 | 负责 / 主导 / 承担 / 牵头 / 推进 | 描述在项目中承担角色 |
| 帮忙 | 支持 / 协同 / 配合 / 协助 | 描述配合他人工作 |
| 做了很多 | 覆盖 / 涵盖 / 贯穿 | 描述工作量大或范围广 |
| 开始做 | 启动 / 推进 / 展开 / 落地 | 描述新启动的事项 |
| 还在做 | 推进中 / 迭代中 / 持续优化 | 描述未完成的工作 |
| 做完了 | 已交付 / 已上线 / 已完成 | 描述已完成的工作 |

## 使用原则

1. **只换词不换事实**：动词升级是让表达更专业，不是编造数据或夸大成果
2. **一个顶一个**：不要为了高级把"做了"全部改成"战略性驱动"
3. **看人下菜**：开发岗用"重构/优化"，运营岗用"增长/转化"，管理岗用"规划/推进"
4. **不要过度**：如果用户做的事真的就是"帮忙送了个文件"，不要在动词上硬凹，诚实更重要
