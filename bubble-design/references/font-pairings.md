# 中英文经典字体搭配速查表

每组搭配含场景推荐和获取方式。

---

## 字体搭配原则

1. **一粗一细**：标题用粗体，正文用常规体。反差 = 层次感
2. **一黑一宋**：黑体标题 + 宋体正文是最经典的中文搭配
3. **不要超过 2 种字体**：超过 2 种会显乱。用同一种字体的不同字重来制造变化
4. **英文搭配**：中文黑体 → 英文无衬线，中文宋体 → 英文衬线
