# Canva / PS 快速套用指南

拿到设计规范后，在 Canva 或 PS 中 10 分钟出图的操作步骤。

---

## 在 Canva 中套用（推荐非设计师）

Canva 是免费在线设计工具（canva.cn 或 canva.com），不需要下载安装。

### Step 1：新建画布

1. 打开 Canva → 右上角「创建设计」
2. 选择「自定义大小」→ 输入方案中给出的尺寸（如 1080×1440px）→ 「创建新设计」

### Step 2：设置背景色

1. 点击空白画布 → 上方工具栏出现颜色图标
2. 点击颜色图标 → 点击「+」添加新颜色
3. 在色号框中输入方案中的背景色号（如 `#FFF8F0`）→ 确定

### Step 3：添加文字

1. 左侧菜单 →「文字」→ 点击「添加标题」或「添加正文」
2. 输入方案中的文案
3. 选中文字 → 上方工具栏：
   - **字体**：下拉框搜索方案中的字体名（如"思源黑体"）。如果找不到，用系统预装的黑体/宋体替代
   - **字号**：直接输入方案中的 pt 值
   - **颜色**：点击文字颜色 → 输入方案中的色号
   - **加粗/常规**：按方案中的字重选择

### Step 4：摆放位置

- 用鼠标拖动文本框到方案中版式图所示的位置
- Canva 会自动显示对齐参考线（粉色线），帮助对齐
- 如果方案给了具体间距，在「位置」面板中直接输入 X/Y 坐标

### Step 5（可选）：添加装饰元素

- 左侧「素材」→ 搜索关键词（如"圆圈""线条""抽象"）
- 选择与方案配色一致的素材拖入画布
- 调整素材颜色：选中素材 → 上方颜色图标 → 输入方案中的点缀色号

### Step 6：导出

- 右上角「分享」→「下载」
- 文件类型：PNG（手机预览）/ JPG（一般用）/ PDF 打印（印刷用）
- 点击「下载」

## 在 Photoshop 中套用

### Step 1：新建文件

- 文件 → 新建
- 宽×高：输入方案尺寸
- 分辨率：72（屏幕用）/ 300（印刷用）
- 颜色模式：RGB（屏幕用）/ CMYK（印刷用）
- 点击「创建」

### Step 2：填充背景

- 点击工具栏底部的前景色
- 在色号框（#）中输入方案中的背景色号 → 确定
- Alt+Delete 填充背景色

### Step 3：添加文字

- 工具栏选「横排文字工具」（T）
- 在画布上点击，输入文案
- 选中文字，在顶部属性栏设置：
  - 字体：下拉框选方案中的字体（如没安装，先在 Adobe Fonts 或 Google Fonts 安装）
  - 字号：直接输入 pt 值
  - 颜色：点击色块，输入方案中的色号

### Step 4：对齐与间距

- 选中图层 → Ctrl+A 全选 → 用顶部对齐工具（水平居中/垂直居中）
- 微调位置：用方向键，或 V 键切换移动工具拖动
- 精确间距：在属性面板输入 X/Y 坐标

### Step 5：导出

- 文件 → 导出 → 导出为
- 格式：PNG（透明背景）/ JPG（有背景）/ PDF（印刷）
- 品质：100%（最高）
- 点击「导出」

## 在 PPT/Keynote 中套用

PPT 也是一个被低估的设计工具，很多简单设计完全够用。

### Step 1：设置画布

- PPT：设计 → 幻灯片大小 → 自定义 → 输入宽度和高度
- Keynote：文稿 → 幻灯片大小 → 自定义

### Step 2：填充背景

- 右键空白处 → 设置背景格式 → 纯色填充 → 颜色 → 其他颜色 → 输入色号

### Step 3：添加文字

- 插入 → 文本框 → 输入文案
- 选中文字 → 开始 → 字体/字号/颜色
- PPT 的颜色选取器支持直接输入色号（自定义 → #XXXXXX）

### Step 4：导出为图片

- 文件 → 另存为 → 文件类型选 PNG 或 JPEG
- 如果只要当前页：文件 → 导出 → 更改文件类型 → PNG

## 通用技巧（任何工具都适用）

### 输入色号

任何设计工具都有色号输入框，通常长这样：
- 一个颜色方块 + 一个文本框写着 `#000000`
- 直接把方案里的色号粘贴进去（如 `#FF6B35`）

### "我找不到方案里说的字体"

原因：方案推荐的字体没安装在电脑上。

解决：
1. 优先：去 Google Fonts（fonts.google.com）或字体官网下载安装（免费）
2. 备选：找一个相似的代替
   - 黑体类 → 系统的「黑体」「微软雅黑」
   - 宋体类 → 系统的「宋体」「仿宋」
   - 圆体类 → 系统的「幼圆」

### 字号 pt 和 px 的关系

Canva 和 PPT 用 pt，PS 用 px。对于屏幕显示（72dpi）：
- 1pt ≈ 1.33px
- 直接当 1:1 用也可以，差别在非印刷品上肉眼不可见

### 印刷品额外注意

如果方案是印刷用途（海报打印、名片印刷）：
1. 颜色模式设为 CMYK（PS：图像 → 模式 → CMYK）
2. 分辨率设为 300dpi
3. 四边预留 3mm 出血（印刷厂裁切的误差空间）
4. 导出 PDF 发给印刷厂，不要导出 JPG（会压缩损失质量）
