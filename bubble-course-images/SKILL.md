# 课程推广图文生成器

## 它做什么

输入一个课程/产品的基本信息，自动生成一套 **4 张推广图文页面**：

| 页面 | 作用 | 内容 |
|------|------|------|
| **01-主图** | 吸引点击的封面 | 产品名称 + 一句话卖点 + 视觉主图 + 核心标签 |
| **02-收获清单** | "你能得到什么" | 4 项具体交付物，每项有标题+描述 |
| **03-对比页面** | "为什么选我们" | 左右对比：替代方案（左边划掉）vs 本产品（右边高亮） |
| **04-适合人群** | "谁该买/谁别买" | 3 类目标用户画像 + 底部信任数字 |

每张页面都是 **独立的 HTML 文件**，打开浏览器就能截图使用，也可以打印为PDF。

## 生成规范

### 每张页面必须包含

**01-主图**
- 大标题（产品名称，50-56px字号）
- 一句话卖点（18px，灰色）
- 视觉中心（笔记本电脑插图，CSS绘制）
- 3个核心标签（底部胶囊按钮样式）
- 品牌角标（右下角，英文名，淡色）

**02-收获清单**
- 标题：你能得到什么 / 你收到的东西
- 副标题：一句话打消疑虑（如"下单后立刻到手，一个不少"）
- 4个交付物卡片，每个包含：图标 + 标题 + 描述（描述中可以高亮关键信息）
- 底部CTA（行动号召）：一行高亮文字

**03-对比页面**
- 标题："XX vs 这个"（左边划掉样式）
- 4行对比，每行左列（灰底+✕符号）vs 右列（白底+橙色左边框+✓符号）
- 底部高亮总结框（橙色渐变背景，白色大字）

**04-适合人群**
- 标题："适合谁" + 副标题说明"不适合就不建议买"
- 3个用户画像卡片，每个包含：图标 + 用户类型标题 + 用户口头禅 + 为什么适合
- 底部信任数字（人数+保证语）

### HTML 文件规范

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<style>
  /* 所有CSS内嵌，不引外部文件 */
  /* 不使用webfont，只用系统自带字体 */
  /* 图标用内嵌SVG，不引外部图片 */
  /* 插图用CSS绘制 */
</style>
</head>
<body>
  <!-- 纯HTML+CSS，不依赖JavaScript -->
</body>
</html>
```

### ⚠️ 关键规则

1. **零外部依赖**：不引用任何外部CSS、字体、图片、JS。100% 自包含。
2. **系统字体**：只用 `PingFang SC`、`Microsoft YaHei`、`Noto Sans SC`、系统默认字体
3. **SVG图标**：所有图标用内嵌SVG矢量图，不用emoji（不同系统显示不一致）
4. **CSS插图**：笔记本电脑等装饰元素用CSS绘制，逼真且不依赖图片
5. **指定宽高**：body设置固定width/height，确保截图尺寸一致
6. **不溢出**：body设置 `overflow: hidden`，内容不能超出

## 交互规则

1. **信息不全时主动补全**：如果用户只给了产品名称，我会根据产品类型自动推断交付物、对比维度、目标人群，生成后再让用户确认。
2. **修改不重来**：用户说"把标题改成XX"或"第三个交付物换成YY"，我只改那一处，不重新生成全部。
3. **配色不满意可切换**：用户说"换个清新绿"或"太暖了换冷色"，我调整CSS配色方案。
4. **保持文件管理**：所有生成的文件保存在用户指定的同一文件夹中，不散落。
