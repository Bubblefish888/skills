你猜我发现了什么？问题根本不在于MES系统本身，而在于这家企业的管理基础——三个大坑。

root cause #1

01

流程混乱

3条工艺路径，全靠老师傅脑子里的经验

过去：老张走了20年，知道什么时候走A路、什么时候走B路
↓
上线后：工人嫌麻烦，要么乱选、要么不录

结果：系统记录的流程 ≠ 实际发生的流程

第一个坑：流程混乱。这家企业的生产工艺其实有3条路径，但过去全靠老师傅的经验来决定走哪条路。老张走了20年，他知道什么时候该走A路、什么时候该走B路，但这个知识从来没有被写下来过。MES系统上线后，要求工人必须在系统里选择路径。结果工人嫌麻烦，要么乱选一个，要么干脆不录。系统记录的流程和实际发生的流程，完全是两回事。

root cause #2

02

权责不清

设备坏了谁修？过去全靠打电话叫人

过去：车间主任打电话 → 维修工来了就修 → 修完就走 → 没人记录
↓
上线后：维修工觉得被监视，拖到最后一刻才录入，数据全是错的

结果：系统记录的时间比实际长好几倍

第二个坑：权责不清。设备坏了谁负责修？过去是车间主任打电话叫维修工，维修工来了就修，修完了就走。至于什么时候来的、花了多长时间修好的，没人记录。MES系统上线后，维修工需要在系统里登记响应时间和完成时间。结果维修工不干了——他觉得这是在监视他。于是出现了一个很有意思的现象：维修工每次维修都拖到最后一刻才录入系统，系统记录的时间比实际时间长了好几倍。数据全是错的。

root cause #3

03

数据不准

同一个零件，3个部门3个不同编码

A车间："BJ-001"
B车间："配件-01"
仓库："标准件-A类"

结果：系统里有料，现场找不到 — 生产停线

第三个坑：数据不准。这家企业的物料编码规则是10年前定的，当时只有一个车间、两条产线。现在发展到三个车间、十几条产线，但编码规则从来没更新过。结果同一个零件在不同部门有3个不同的编码。MES系统需要按编码来扣库存，结果经常出现"系统里有料、现场找不到"的情况。生产停线，工人骂系统，系统说"不关我的事"。你看，这三个问题，没有一个是MES系统本身的缺陷。但系统把它们全部放大了——原来靠人糊弄过去的事情，现在系统不让你糊弄了。

好，案例讲完了。我们来提炼一下底层逻辑。我给大家一个三阶段模型，这个模型是我在几十个项目里总结出来的。

第一阶段：管理标准化。把"人治"变成"法治"。业务流程显性化、数据标准统一、异常处理有规则。目标是任何一个人照着流程做，能做到80分以上。

第二阶段：流程在线化。管理标准化之后，才能把流程搬到线上。把标准化后的流程固化到系统里，让系统来"强制执行"你的规则。目标是流程跑在系统里，而不是跑在人的嘴巴里。

第三阶段：数据智能化。当你的流程在线化跑通了，积累了足够的高质量数据，这时候AI才能发挥作用。AI可以做三件事：自动化、预测、优化。

现在问你一个问题：很多企业做数字化转型，从哪个阶段开始？答案是：他们直接从0跳到第三阶段。老板听说AI很火，就说"我们也要上AI"。但回头一看，自己的流程还是靠Excel传、数据还是靠人工报、管理还是靠老板拍脑袋。这种情况下上AI，就像在一栋地基都没打好的房子上装修——装修得再豪华，房子该塌还是塌。正确的顺序是：一步一步来。先标准化，再在线化，最后智能化。顺序不能错，跳步必翻车。

第三阶段，数据智能化。当流程在线化跑通、积累了高质量数据，AI才能发挥作用。AI做三件事：自动化——替代重复性人力工作；预测——告诉你接下来可能发生什么；优化——告诉你怎么做效果更好。但前提是高质量数据加在线化流程，否则就是垃圾进垃圾出。
