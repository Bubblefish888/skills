## 构图原则

### 口播构图
```
┌─────────────────────────────┐
│                             │ ← 头顶留10-15%空间（不要贴顶）
│         👤 人物              │
│         居中或              │
│         偏左1/3             │
│                             │
│   眼睛在画面上1/3处          │ ← 黄金分割线
│                             │
│                             │
│     字幕区域（底部）          │ ← 不要挡脸
└─────────────────────────────┘

关键数值（竖屏9:16）：
- 眼睛位置：画面从上往下约35-40%处
- 头部上方留白：10-15%
- 字幕位置：画面底部15-20%区域
- 安全区：画面边缘各留5%（不同手机裁剪可能不同）
```

### 常用构图方式
| 构图 | 方法 | 适用 |
|------|------|------|
| 中心构图 | 人物居中 | 口播主体、强调观点 |
| 三分法 | 人物偏左/右1/3 | 旁边放文字/产品 |
| 对角线 | 画面元素沿对角线 | 动感、时尚、年轻化 |
| 留白构图 | 人物占一边，另一边大面积留白 | 情绪类、金句类 |

## 灯光方案

### 方案A：自然光（最省事）
```
☀️ 自然光方案
- 时间：上午9-11点 / 下午3-5点（光线柔和）
- 位置：面对窗户，光从正面或侧面45°来
- 避免：背光（人脸黑）、正午顶光（眼袋阴影）
- 补光：白色泡沫板/白墙反射光补暗面
- 效果：真实、柔和、生活化
```

### 方案B：单灯方案（最常用）
```
💡 单灯 + 自然光
- 主灯：环形灯或柔光灯，放在手机正后方偏上
- 位置：高于眼睛15-20°，距离面部50-80cm
- 色温：4000-5000K（中性偏暖）
- 亮度：调节到面部明亮但不刺眼
- 效果：眼神光明显，面部立体
```

### 方案C：双灯方案（专业感）
```
💡💡 双灯方案
- 主灯（Key Light）：正面偏上，面部主体照明
- 辅灯（Fill Light）：侧面45°，消除主灯产生的阴影
- 功率比：主灯：辅灯 ≈ 2:1 或 3:1
- 可选+背景灯：给背景增加层次
- 效果：专业、立体、有质感
```

### 色温参考
| 色温 | 感觉 | 适用场景 |
|------|------|---------|
| 2700-3200K | 暖黄、温馨 | 生活类、情感类、家居 |
| 4000-4500K | 自然白 | 知识类、口播、日常 |
| 5000-5600K | 冷白、专业 | 科技、职场、美妆 |
| 6000K+ | 清冷 | 极简、科技感、慎用（显脸色差） |

## BGM策略

### BGM类型速查

| 内容类型 | 推荐BGM风格 | BPM范围 | 备注 |
|---------|------------|---------|------|
| 情绪/共鸣 | 钢琴独奏、轻弦乐 | 60-80 | 音量低，不要抢人声 |
| 干货/知识 | 轻电子、Lo-fi、无BGM | 80-100 | 可以在讲到重点时完全去掉BGM |
| 励志/正能量 | 渐进式管弦、流行钢琴 | 90-120 | 配合内容高潮推起 |
| 剧情/故事 | 电影配乐类、氛围音效 | 变化 | 跟着情绪走 |
| 搞笑/轻松 | 俏皮电子、爵士 | 100-130 | 可以加音效 |
| 产品展示 | 现代电子、节奏感 | 90-110 | 画面切换可以对BGM的重拍 |

### BGM使用节奏
```
0s ──────── 开场：BGM起（吸引注意，略高于正常音量）
3s ──────── 开始说话：BGM降低到背景级别（人声的20-30%）
15s ─────── 干货展开：BGM再降低或完全去掉
35s ─────── 峰值钩：BGM重新推起（配合情绪）
45s ─────── CTA：BGM渐弱
55s ─────── 结束：BGM淡出
```

## 音效使用

### 常用音效点位
| 时机 | 音效 | 作用 |
|------|------|------|
| 重点词出现 | 叮 / 咚 | 强调 |
| 转折 | 刹车声 / 倒带声 | 打破节奏 |
| 画面切换 | whoosh / swoosh | 流畅转场 |
| 惊讶/反转 | 重音鼓 / 心跳声 | 制造冲击 |
| 展示成果 | 相机快门 | 标记"证据" |
| 幽默点 | 鸭子叫 / 弹簧声 | 制造笑点 |

💡 音效原则：一条视频音效不超过5处，过犹不及。

## 字幕设计参考

### 字体选择
| 风格 | 推荐字体 | 适用 |
|------|---------|------|
| 现代简洁 | 思源黑体 / 阿里巴巴普惠体 | 知识口播、职场 |
| 温柔文艺 | 思源宋体 / 手写体 | 情感、生活方式 |
| 活泼年轻 | 站酷快乐体 / 圆体 | 搞笑、娱乐 |
| 力量感 | 站酷高端黑 / 造字工房 | 观点输出、态度类 |

### 字幕排版
- 基础字号：画面宽度的5-6%（竖屏约30-36px）
- 关键词字号：比基础大30-50%
- 每行字数：不超过15个字（竖屏）
- 行数：1-2行最佳，最多3行
- 位置：画面底部往上15-20%
- 关键词强调方式：放大/变色/加粗（选一种，不要全用）
