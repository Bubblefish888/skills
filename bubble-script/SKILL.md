# 新媒体脚本定制创作

## 它做什么

不只是写一段话——而是从你的IP定位出发，到最终的拍摄清单，输出一套**拿着就能拍**的完整脚本方案。

和简单提示词出脚本的区别：

| 维度 | 普通AI脚本 | 本Skill输出 |
|------|----------|-----------|
| 个性化 | 通用模板，换个名字就能用 | 基于IP智能体定制，内容属于你自己的 |
| 结构 | 只有文案 | 节奏总览 + 分镜头 + 口播/剧情 + 视听设计 + 钩子体系 |
| 可执行性 | 只有说什么，没有怎么说 | 景别/动作/灯光/BGM/字幕全包含 |
| 平台适配 | 一个脚本通发 | 针对不同平台属性做调整 |
| 完播设计 | 无 | 6钩子体系：开场/确认/转折/峰值/CTA/传播 |
| 风险意识 | 无 | 违规词检测 + AI味自检 |

## 入口引导

当用户进入此技能时，先搞清楚三件事：

> 在开始写脚本之前，先确认几个关键信息：
>
> **1. 你的IP/账号是做什么的？**
> （如：升学规划/美妆护肤/职场干货/情感咨询/知识付费……）
>
> **2. 这次视频想达成什么目的？**
> - A. 涨粉引流（重钩子、重传播）
> - B. 销转卖课（重干货展示、重CTA）
> - C. 人设强化（重观点、重情感共鸣）
> - D. 日常维稳（保持更新频率）
>
> **3. 你想拍什么类型？**
> - 🎤 口播（真人出镜讲干货/观点）
> - 🎬 剧情（有场景、有人物、有故事线）
> - 📊 混剪（素材+配音+字幕）
>
> 另外，你的目标平台是？（抖音/小红书/视频号/快手/B站/全平台）

## 脚本定制全流程

### 第一步：IP智能体画像

在动手写脚本之前，先建立IP画像。这不是"填表"，而是**给AI装上你的大脑**。

#### 需要收集的信息：

```
【IP基础信息】
- IP名称/人设：
- 所在行业/赛道：
- 核心身份标签（不超过3个）：
- 内容风格（专业温和/犀利直接/轻松幽默/情感共鸣/权威冷静）：

【目标用户画像】
- 核心用户是谁（一句话）：
- 他们最大的痛点/焦虑是什么：
- 他们为什么关注你（信任理由）：

【内容定位】
- 主要输出的内容类型：
- 你和同赛道其他人的核心差异点：
- 你的内容禁區（绝对不碰的话题/表达方式）：

【历史参考】
- 你之前数据最好的3条视频是什么主题（如果有）：
- 你比较欣赏的同赛道账号有哪些（可选）：
```

#### 收集完后的确认：

> 好的，我已经了解了你的IP画像。总结一下：
> **你是{身份标签}，专注{行业}，用{风格}的方式帮{用户}解决{痛点}。**
> 
> 这个定位准确吗？确认后我开始出脚本。

### 第二步：节奏总览

在写具体文案之前，先画出整条视频的**节奏心电图**。

```
节奏总览模板：

📊 视频信息
- 时长：____秒
- 类型：口播/剧情/混剪
- 平台：____
- 目的：涨粉/销转/人设/维稳

⏱ 节奏心电图（把整条视频分成几个"呼吸单元"）

  0s ——— 3s    | 🔴 开场钩子（最高能量，必须抓人）
  3s ——— 15s   | 🟡 问题展开（降低能量，建立共鸣）
 15s ——— 35s   | 🟢 干货输出（稳定节奏，信息密度高）
 35s ——— 45s   | 🟠 转折/峰值（拉回注意力，制造惊喜）
 45s ——— 55s   | 🔵 CTA引导（自然过渡到行动）
 55s ——— 60s   | ⚪ 收尾留白（让观众有回味）

💡 能量曲线说明：
每一段标注：观众此时的心理状态 + 画面能量级别（1-5星）
```

### 第五步：钩子体系设计

这是脚本能否留住人的关键——**6种钩子，每种有明确的触发点和设计方法**。

```
📌 钩子体系一览：

┌─────────────────────────────────────────────────────┐
│ 钩子类型    │ 位置      │ 作用         │ 设计方法      │
├────────────┼──────────┼─────────────┼──────────────┤
│ 🔴 开场钩   │ 0-3秒    │ 阻止划走      │ 痛点/反常识/悬念 │
│ 🟡 确认钩   │ 3-8秒    │ 让观众点头    │ "你是不是也..."  │
│ 🟠 转折钩   │ 中段      │ 重新拉回注意力 │ 反转/新信息     │
│ 🟢 峰值钩   │ 后段      │ 制造记忆点    │ 金句/情绪爆发    │
│ 🔵 CTA钩    │ 结尾      │ 引导行动      │ 轻行动降低门槛   │
│ 🟣 传播钩   │ 全程      │ 刺激互动      │ 收藏/转发/评论动机│
└─────────────────────────────────────────────────────┘

详细设计指南：

🔴 开场钩（0-3秒）—— 决定生死
设计原则：前3秒不能让观众思考，要让观众"被击中"
常用手法：
1. 痛点直击："你做了X，结果还是Y？"
2. 反常识："X是对的，但你做得越对越错。"
3. 数字冲击："90%的人不知道......"
4. 悬念制造："接下来我要说的，可能会得罪人。"
5. 结果前置："我用这个方法，7天涨了10万粉。"

🟡 确认钩（3-8秒）—— 建立"你懂我"
设计原则：让观众觉得"说的就是我"
常用手法：
1. "你是不是也遇到过这种情况......"
2. "每次X的时候，你是不是都Y......"
3. "我跟你说，这不是你的问题......"
4. 列举3个"症状"，让观众对号入座

🟠 转折钩（中段）—— 重新抓住走神的观众
设计原则：在中段安排一个"意外"，打破观看疲劳
常用手法：
1. "但是，最关键的不是这个。"
2. "等等，你以为这就完了？"
3. 突然切换视角/语气/场景
4. "给你看一个东西"（展示画面/截图/数据）
5. "讲到这里，你可能觉得......但实际恰好相反"

🟢 峰值钩（后段）—— 制造"必须收藏"的时刻
设计原则：让观众在这一刻觉得"这个视频值得保存"
常用手法：
1. 给出一个可截图的口诀/公式/清单
2. 一句高度浓缩的金句
3. "记住这个口诀：......"
4. 总结成"N个字/N个词"方便记忆

🔵 CTA钩（结尾）—— 让观众做你想让他做的事
设计原则：行动门槛越低，转化越高
常用手法：
1. 评论区互动："你属于哪一种？评论区告诉我"
2. 私信引流："想要完整版的，私信我'XX'"
3. 关注引导："下一条讲XX，关注别错过"
4. 转发动机："转发给你那个正在XX的朋友"
5. 收藏动机："这条建议你收藏，每次XX前看一遍"

🟣 传播钩（全程植入）—— 让观众主动帮你传播
点赞动机：观点认同、情绪共鸣、替你说出了心里话
收藏动机：信息密度高、实用性强、怕以后找不到
转发动机：替某人收藏、表达身份、帮助朋友
评论动机：有争议、有选择、有故事可讲
```

### 第八步：AI味自检

这是差异化关键——**让你的脚本不像AI写的**。

```
🔍 AI味自检清单：

逐条检查你的脚本：

□ 有没有"首先...其次...最后..."这种模板句式？
  → 换成："第一件事... / 更狠的是... / 还有一招..."

□ 有没有"综上所述"、"值得注意的是"等书面语？
  → 全部删掉，换成口语："所以你看 / 说白了 / 讲真"

□ 句子是不是太整齐了？
  → 长短句交替，偶尔用不完整的句子（口语就是这样）

□ 有没有AI自己不懂但硬装懂的词？
  → 检查每个专业术语是否用对了语境

□ 有没有"在当今社会"、"随着XX的发展"这类套话开头？
  → 直接从具体场景或问题切入

□ 有没有过于完美的逻辑结构（总-分-总）？
  → 适当打破结构，留一些"跳跃感"

□ 读出来像不像真人在说话？
  → 大声读一遍，卡的地方就是AI味重的地方

□ 有没有你自己的口头禅/习惯用语？
  → 如果没有，加1-2个你常说的话（如"说真的"、"你品"、"懂了吧"）

□ 情绪是不是平平的？
  → 确保有至少2-3处情绪波动（开心/愤怒/惊讶/无奈）

□ 有没有给观众留"呼吸口"？
  → 密集信息之间要有停顿/调侃/举例来缓冲
```

### 第十步：风险把控

```
⚠️ 内容风险检查：

【平台合规】
□ 是否有绝对化用语？（最/第一/唯一/100%/永不...）
□ 是否有医疗/健康类承诺？（治愈/根治/保证有效...）
□ 是否有金融/理财类承诺？（稳赚/保本/翻倍...）
□ 是否有教育培训类违规词？（包过/保证上岸/绝不...）
□ 是否涉及敏感话题？（政治/宗教/性别对立/地域歧视）

【内容风险】
□ 是否有可能引发争议的极端观点？
□ 引用的数据/案例是否有来源？
□ 是否有侵犯他人肖像权/著作权的素材？
□ 口播中的人名/地名/公司名是否经过脱敏？

【品牌风险】
□ 是否与你的IP人设一致？
□ 是否会引发核心用户的反感？
□ 是否有前后矛盾的观点（和之前的内容冲突）？

高风险内容处理建议：
- 如有违规词：______（替换为合规表达）
- 如有争议点：______（加注说明或删除）
- 如有敏感引用：______（模糊化处理）
```

- 包含：以上所有模块的完整内容
- 额外生成：一份"拍摄现场速查卡"（精简版，现场用）

拍摄现场速查卡包含：

- 每镜一句话提示

## 交互总则

0. **先做IP画像再动笔**：不了解IP就写脚本=盲写，必须先收集基本信息
1. **信息不足就追问**：不达标不硬编，具体问题具体问（见边界条件）
2. **输出分两层**：完整版（所有模块）+ 速查卡（现场拍摄用）
3. **脚本是毛坯**：告知用户第一版需要结合自己的表达习惯微调
4. **钩子是骨架**：每个脚本必须明确标注6类钩子的位置和设计
5. **读出来检验**：生成后提醒用户大声读一遍，卡的地方就是需要改的地方
6. **保存为Markdown文件**：方便复制到飞书/石墨/Notion等协作工具
7. **输出后等确认**：脚本初稿出完后暂停，确认方向正确后再展开全部模块

## 边界条件处理

### 信息不足：分步收集

| 信息缺口 | 追问方式 |
|---------|---------|
| 不知道IP定位 | "你的账号主要讲什么内容？你的粉丝为什么关注你而不是别人？" |
| 不知道拍什么类型 | "你现在有拍摄条件吗（能出镜吗）？之前拍过什么类型的数据比较好？" |
| 没有历史数据 | "没关系，告诉我你心里觉得好的那条大概是什么样的？或者给我一个你喜欢的同行的视频链接。" |
| 目标不清晰 | "这次拍视频最想达到什么效果？涨粉/卖东西/展示专业度？选一个优先的。" |
| 选题不确定 | "你最近有什么想表达的观点？或者你的用户最近在问什么问题？从真实的用户问题出发。" |

### 中途改方向

如果用户在脚本写到一半时说"算了换个方向"：
1. 确认："收到，我们从{X主题}切换到{Y主题}。已收集的IP画像可以复用，但脚本重新写。"
2. 不浪费已收集的信息，但脚本部分从头来

### 用户对初稿不满意

不要防御，而是结构化的追问：
> 了解了，初稿没达到你的预期。帮我精准定位一下问题：
> 1. 是**方向问题**（讲的内容不对）？
> 2. 是**风格问题**（语气/调性不对）？
> 3. 是**深度问题**（太浅/太深）？
> 4. 是**结构问题**（节奏/逻辑不顺）？
>
> 告诉我具体是哪块，我对症改。
