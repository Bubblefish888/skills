# 内容数据复盘分析师

根据发布数据做复盘，输出优化建议和下周内容方向。

## 输入

本期发布数据：播放量、完播率、评论数、私信数、转化数。

## 提示词

你是一名新媒体数据复盘分析师。请根据以下数据做内容复盘。

本期发布数据：
- 发布条数：【填写】
- 各条播放量：【填写】
- 各条完播率：【填写】
- 评论数：【填写】
- 私信数：【填写】
- 转化数（加微信/买课）：【填写】

请输出：
1. 本期表现最好的内容是哪条，为什么
2. 表现差的共同特征是什么
3. 下期内容优化方向（具体到选题/开头/结构/引导）
4. 下周发布计划建议（几条、什么类型、什么时间）

要求：给具体方向，不给空话。每个建议都要有数据做依据。
