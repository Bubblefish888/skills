# Excel 数据处理技能

## 它做什么

你只需要说人话，剩下的事交给它。不用学 VLOOKUP、不用背公式、不用描述"A 列是什么 B 列是什么"——直接把 Excel 文件丢进来，说你要什么。

四个核心场景：

| 场景 | 你说 | 输出 |
|------|------|------|
| 数据匹配 | "把两个表的姓名对上" | 可用公式 + 操作步骤 |
| 数据透视 | "按月份和品类汇总销售额" | 透视表设置步骤 + 结果解读 |
| 同比环比 | "对比今年和去年同期" | 计算公式 + 增长率分析 |
| 图表制作 | "展示各区销售占比" | 图表类型推荐 + 制作步骤 |

## 处理流程

无论哪个场景，统一按以下流程：

### Step 1: 读取文件，理解数据结构

用 Python 读取 Excel 文件，获取表的整体结构。输出给用户一个简洁的结构概览：

```markdown
## 文件概览：{文件名}

### Sheet 1: {工作表名}
| 列 | 标题 | 数据类型 | 示例 |
|----|------|---------|------|
| A | 姓名 | 文本 | 张三 |
| B | 部门 | 文本 | 技术部 |
| C | 销售额 | 数字 | 12,500 |
...

- 共 {N} 行数据
- 空值分布：{哪些列有空值}
```

优先使用 `openpyxl` 或 `pandas` 读取。如果文件是 `.xls` 格式，用 `xlrd`。

```bash
python3 -c "
import pandas as pd
df = pd.read_excel('文件路径', sheet_name=None)
for name, sheet in df.items():
    print(f'Sheet: {name}')
    print(f'列: {list(sheet.columns)}')
    print(f'行数: {len(sheet)}')
    print(sheet.head(3).to_string())
    print('---')
"
```

### Step 2: 确认理解

把对人话的理解翻译回给用户确认：

> 我理解你的需求是：{一句话概括}。对应的 Excel 操作是：{操作名}。对吗？

如果用户的人话有歧义（比如"对比两个表"可能是匹配也可能是合并），列出 2-3 种可能让用户选：

> "对比两个表"可以理解为：
> 1. 找出两个表里相同的和不同的（数据匹配）
> 2. 把两个表拼成一个大表（合并）
> 3. 比较两边数字的大小变化（对比分析）
>
> 你想要哪种？

### Step 3: 生成方案

给出公式或操作步骤：

```markdown
## 方案

### 使用公式
```
=VLOOKUP(A2, Sheet2!A:C, 3, FALSE)
```

### 逐步操作
1. 选中 D2 单元格
2. 输入公式 `=VLOOKUP(A2, Sheet2!A:C, 3, FALSE)`
3. 按 Enter
4. 双击 D2 右下角填充柄，自动应用到整列

### 公式说明
- `A2`：在当前表中找谁（姓名）
- `Sheet2!A:C`：去 Sheet2 的 A 到 C 列中查找
- `3`：找到后返回第 3 列（部门）
- `FALSE`：精确匹配
```

### Step 4: 验证 + 常见错误预警

给出 1-2 条验证方法 + 最可能出的错：

```markdown
### 验证方法
- 随机抽查 3 行，看匹配结果是否正确
- 如果结果是 #N/A，检查姓名是否完全一致（有没有空格、错别字）

### 常见报错
- **#N/A**：找不到匹配值 → 检查两边数据是否一致（去除空格、统一全角半角）
- **#REF!**：引用的列被删了 → 检查公式中的列范围是否还存在
```

## 场景一 · 数据匹配

> 用户说"把两边的 XX 对上"、"两个表匹配一下"等。

### 匹配公式选择逻辑

根据用户的数据版本，推荐最合适的公式：

| 你的 Excel 版本 | 推荐函数 | 理由 |
|----------------|---------|------|
| Microsoft 365 / Excel 2021+ | XLOOKUP | 最强大，自动处理找不到的情况 |
| Excel 2019 | VLOOKUP | 兼容性好 |
| Excel 2016 及以下 | INDEX + MATCH | 比 VLOOKUP 灵活，可向左查 |
| WPS 最新版 | XLOOKUP | WPS 已支持 XLOOKUP |
| WPS 旧版 | VLOOKUP | 最保险 |

### 多条件匹配

用户说"两个条件都要对上"时：

```
=XLOOKUP(A2&B2, Sheet2!A:A&Sheet2!B:B, Sheet2!C:C)
```

### 公式
{公式}

### 操作步骤
1. ...
2. ...

### 注意事项
- {版本兼容性提示}

## 场景二 · 数据透视

> 用户说"按 XX 汇总"、"数据透视"、"分类汇总"等。

### 透视表设置引导

不假设用户知道怎么做透视表，每一步都写清楚：

```markdown
## 数据透视方案

### 你的需求
按「月份」和「品类」汇总「销售额」

### 操作步骤

#### Excel 界面操作
1. 点击数据区域任意一个格子
2. 菜单栏 → **插入** → **数据透视表**
3. 确认数据范围已自动选中全部数据 → 确定
4. 在右侧字段列表中：
   - 把「月份」拖到 **行**
   - 把「品类」拖到 **列**
   - 把「销售额」拖到 **值**

#### WPS 界面操作
1. 点击数据区域任意一个格子
2. 菜单栏 → **插入** → **数据透视表**
3. 操作同上

### 值汇总方式
- 默认是「求和」。如果需要改为「计数」「平均值」：
  - 点击值区域的「销售额」→ **值字段设置** → 选择计算类型

### 结果检查
- 汇总后的总计应等于原始数据总和
- 检查是否有空白行（说明源数据有空值）
```

### 透视表常见需求速查

| 你说 | 透视表怎么设 |
|------|------------|
| 按月份汇总 | 行=月份，值=要汇总的列（求和） |
| 各品类占比 | 行=品类，值=数量（求和）→ 右键 → 值显示方式 → 总计的百分比 |
| 每月各品类明细 | 行=月份，列=品类，值=金额 |
| 每个人做了多少 | 行=姓名，值=数量（计数），值=金额（求和） |
| 按年份对比 | 行=年份，列=产品，值=金额 |

## 场景三 · 同比环比

> 用户说"对比今年和去年"、"算增长率"、"同比"、"环比"等。

### 公式模板

**同比增长率（与去年同期比）：**

```
=(今年数据 - 去年同月数据) / 去年同月数据
```

在 Excel 中：
```
=(B2-C2)/C2
```
然后设置单元格格式为「百分比」。

**环比增长率（与上个月比）：**

```
=(本月 - 上月) / 上月
```

在 Excel 中：
```
=(B2-B1)/B1
```

### 输出模板

```markdown
## 同比环比分析方案

### 你的需求
{一句话概括}

### 计算公式

#### 同比增长率
公式：`=(B2-C2)/C2`
含义：（今年 - 去年）/ 去年 × 100%

#### 环比增长率
公式：`=(B2-B1)/B1`
含义：（本月 - 上月）/ 上月 × 100%

### 操作步骤
1. 在数据旁新增一列，命名为「同比增长率」
2. 第一行输入公式 `=(B2-C2)/C2`
3. 将该单元格格式设为「百分比」，小数位数 1 位
4. 双击填充柄应用到整列

### 结果解读
- **正数**：增长（绿色标注）
- **负数**：下降（红色标注）
- **#DIV/0!**：去年同期为 0，无法计算增长率（标记为"无基期数据"）

### 可视化建议
- 用「组合图」：柱子显示绝对值，折线显示增长率
- 正增长用绿色，负增长用红色
```

## 场景四 · 图表制作

> 用户说"做个图"、"展示趋势"、"对比一下"、"占比"等。

### 图表选型决策树

根据用户的数据和分析目的推荐图表：

| 你说 | 推荐图表 | 为什么 |
|------|---------|--------|
| 看趋势/变化 | 折线图 | 时间序列首选 |
| 对比大小/排名 | 柱状图 | 分类对比最直观 |
| 看占比/份额 | 饼图（≤6项）或环形图 | 超过6项用柱状图 |
| 两个指标的关系 | 散点图 | 看相关性 |
| 同时看趋势和对比 | 组合图 | 柱子+折线双轴 |
| 多维度分布 | 雷达图 | 综合评估用 |
| 数量分布 | 直方图 | 看数据集中在哪个区间 |
| 区域销售对比 | 地图图表 | 有地理数据时用 |

### 图表制作原则

会在生成方案时自动应用：
- 标题要能看懂（不用"图表1"，用"2024年各区域销售额对比"）
- 数据标签直接标在图上（不用对着坐标轴数）
- 颜色有区分度但不超过 5 种
- 删除默认的网格线和图例边框（干净）

## 公式报错排查

用户描述或提供了报错信息时，按以下速查表诊断（详见 `references/error-fix.md`）：

| 报错 | 最常见原因 | 一句话修复 |
|------|-----------|-----------|
| #N/A | VLOOKUP 没找到匹配值 | 检查两边数据是否完全一致 |
| #REF! | 引用的单元格被删了 | 重新选择公式引用的区域 |
| #VALUE! | 数据类型不对（文本当数字算） | 检查引用格是否包含数字 |
| #DIV/0! | 除以了 0 或空格 | 加 IF 判断：`=IF(B2=0,"",A2/B2)` |
| #NAME? | 函数名写错了 | 检查拼写，中文版用中文函数名 |
| #NUM! | 数字太大或不合法 | 检查是否有无效数字 |
| #NULL! | 区域引用之间没交集 | 检查区域引用是否正确 |
| ##### | 列宽不够 | 拉宽列 |

### WPS 特有问题

- WPS 的函数名和 Excel 可能不同（如 `SUM` vs `求和`）
- WPS 分隔符默认用 `、` 不是 `,`
- 优先输出 WPS 兼容的公式写法

## 边界条件处理

### 输入不足：先拒后问

| 情况 | 最低标准 | 不达标时追问 |
|------|---------|------------|
| 文件没给 | 必须给出文件路径 | "你的 Excel 文件在哪个路径？或者直接拖进来。" |
| 意图不清 | 至少说清楚想要什么 | "你想对这个表做什么？比如：把两边的名字对上、按月份汇总、看占比？随便用人话说就行。" |
| 多个 Sheet | 不确定用哪个 Sheet | 先列出所有 Sheet 名和结构概览，问："这个文件有 {N} 个工作表，你要处理哪个？" |

### 文件处理异常

| 问题 | 处理方式 |
|------|---------|
| 文件太大（>50MB） | 先只读前 1000 行，告知用户："文件比较大，先看前 1000 行的结构，确认没问题再全量处理" |
| .xls 格式 | 用 `xlrd` 代替 `openpyxl`，提醒用户：".xls 是旧格式，建议另存为 .xlsx 后处理更稳定" |
| 加密文件 | 告知用户："文件有密码保护，请先解密或用密码打开后另存一份" |
| 公式报错链 | 如果一个单元格的 #REF! 导致其他单元格连锁报错，先修根因，再告诉用户哪些连带修复了 |
| 合并单元格 | 警告用户："这个表有合并单元格，会导致公式/透视表异常。建议先取消合并再处理" |

### 版本适配策略

看到公式输出时自动带上版本提示：

| 推荐公式 | 适用版本 | 不适用时降级 |
|---------|---------|------------|
| XLOOKUP | 365 / 2021+ / WPS 最新版 | → VLOOKUP 或 INDEX+MATCH |
| FILTER | 365 / 2021+ | → 自动筛选 + 复制 |
| UNIQUE | 365 / 2021+ | → 删除重复项 功能 |
| TEXTSPLIT | 365 / 2021+ | → LEFT/RIGHT/MID 组合 |
| VSTACK | 365 / 2021+ | → 复制粘贴 + Power Query |

**原则**：先推荐最好用的公式，同时给出不适用版本的降级方案。
