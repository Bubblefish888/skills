# 10 个最常见 Excel 难题 · 直接抄答案

每个问题包含：场景 → 一句话方案 → 公式/步骤。

---

## 1. 两个表的名字对上，抓过来另一列的数据

**场景：** 表 1 有姓名和部门，表 2 有姓名和工资。想把表 2 的工资按姓名匹配到表 1。

**公式（Excel 365 / WPS 新版）：**
```excel
=XLOOKUP(A2, Sheet2!A:A, Sheet2!B:B)
```

**公式（旧版兼容）：**
```excel
=VLOOKUP(A2, Sheet2!A:B, 2, FALSE)
```

**必做检查：** 姓名两边是否有空格？→ 先用 `=TRIM(A2)` 洗一遍。

## 2. 按类别汇总金额/数量

**场景：** 一张销售明细表，想按产品名称汇总销售总额。

**用数据透视表（推荐）：**
1. 点数据区域任一格 → 插入 → 数据透视表 → 确定
2. 行 = 产品名称，值 = 销售额

**用公式：**
```excel
=SUMIF(产品列, "产品名", 金额列)
=SUMIFS(金额列, 产品列, "产品名", 日期列, ">=2024-01-01")
```

---

## 3. 算同比增长率

**场景：** B 列是今年数据，C 列是去年同期数据。

**公式：**
```excel
=(B2-C2)/C2
```
设为百分比格式，保留 1 位小数。

**防止 #DIV/0!：**
```excel
=IF(C2=0, "", (B2-C2)/C2)
```

---

## 4. 把重复的数据删掉，只留一条

**场景：** 客户名单里有重复姓名，需要去重。

**方法一：删除重复项**
选中全表 → 数据 → 删除重复项 → 勾选判断重复的列 → 确定。

**方法二：用公式提取不重复列表（365）：**
```excel
=UNIQUE(A:A)
```

---

## 5. 按条件筛选数据到另一个区域

**场景：** 从销售明细里把某个部门的所有记录筛出来。

**方法（365）：**
```excel
=FILTER(A:D, B:B="技术部")
```

**方法（旧版）：**
选中全表 → 数据 → 筛选 → 在部门列下拉框选"技术部" → 复制 → 粘贴到新表。

## 6. 身份证号提取生日/性别/年龄

**提取生日（18 位身份证）：**
```excel
=DATE(MID(A2,7,4), MID(A2,11,2), MID(A2,13,2))
```

**提取性别（18 位身份证，第 17 位奇数为男）：**
```excel
=IF(MOD(MID(A2,17,1),2)=1, "男", "女")
```

**算年龄：**
```excel
=DATEDIF(DATE(MID(A2,7,4), MID(A2,11,2), MID(A2,13,2)), TODAY(), "Y")
```

## 7. 把一列按分隔符拆成多列

**场景：** "张三,技术部,15000" → 姓名 / 部门 / 薪资 分开。

**方法一（365）：**
```excel
=TEXTSPLIT(A2, ",")
```

**方法二（旧版）：**
选中列 → 数据 → 分列 → 选择"分隔符号" → 勾选"逗号" → 完成。

---

## 8. 多条件求和/计数

**场景：** 统计"技术部"在"2024 年 1 月"的销售总额。

**多条件求和：**
```excel
=SUMIFS(金额列, 部门列, "技术部", 日期列, ">=2024-01-01", 日期列, "<=2024-01-31")
```

**多条件计数：**
```excel
=COUNTIFS(部门列, "技术部", 日期列, ">=2024-01-01", 日期列, "<=2024-01-31")
```

## 9. 合并多个单元格内容

**场景：** 把 A2(姓名)、B2(部门)、C2(职位) 合成一格。

**方法（365）：**
```excel
=TEXTJOIN(" - ", TRUE, A2, B2, C2)
```
结果：张三 - 技术部 - 高级工程师

**简便方法：**
```excel
=A2 & " - " & B2 & " - " & C2
```

## 10. 把多个工作表/文件的数据合到一起

**场景：** 12 个月的销售数据分散在 12 个 Sheet 或 12 个文件里。

**用 Power Query（推荐，所有版本适用）：**
1. 数据 → 获取数据 → 从文件夹（或从工作簿）
2. 选择文件夹/文件 → 合并 → 合并并加载
3. 之后源文件更新了只需右键刷新

**用公式（365）：**
```excel
=VSTACK(Sheet1:Sheet12!A2:D100)
```

**不用公式：**
打开一个新 Sheet → 依次复制粘贴各月数据（确保表头只保留一行）。

## 附加：WPS 用户注意

| 问题 | WPS 操作方法 |
|------|------------|
| 数据透视表 | 插入 → 数据透视表（路径和 Excel 一样） |
| Power Query | WPS 个人版可能没有，企业版有，或用公式替代 |
| 函数名 | 支持中英文混用，如 `=SUMIF` 和 `=SUMIF` 都可以 |
| 分隔符 | WPS 默认用 `、`（中文顿号），可以手动切换 |
| TEXTSPLIT 等新函数 | WPS 较新版本已支持，旧版本用分列功能替代 |
